# Data Dictionary

> All data in this prototype is entirely synthetic, generated by `generate_data.py`.
> No real company, client, employee or financial data is used.

---

## Source 1: CRM Leads (`data/crm_leads.csv`)

Represents leads from a CRM system such as GoHighLevel (GHL).

| Field | Type | Format | Example | Notes |
|---|---|---|---|---|
| `lead_id` | string | CRM-XXXX | CRM-0001 | Unique; primary key |
| `created_date` | date | YYYY-MM-DD | 2024-03-15 | Date lead entered the system |
| `source` | category | Title Case | Referral | One of: Referral, Website, Cold Call, LinkedIn, Trade Show, Email Campaign, Partner |
| `owner` | string | Full Name | Alice Johnson | Assigned sales representative |
| `company` | string | Title Case | Apex Corp | Prospect company name; **join key to ops.client_id** |
| `region` | category | Title Case | North | One of: North, South, East, West, Central |
| `pipeline_stage` | category | — | Qualified | One of: New Lead, Qualified, Proposal Sent, Negotiation, Closed Won, Closed Lost |
| `deal_value` | float | USD | 45000.00 | Estimated deal; blank for New Leads |
| `status` | category | — | Open | Derived: Won (Closed Won), Lost (Closed Lost), Open (all others) |
| `last_activity_date` | date | YYYY-MM-DD | 2024-04-01 | Most recent contact/activity |
| `account_segment` | category | — | Enterprise | One of: Enterprise, Mid-Market, SMB |
| `days_since_activity` | int | days | 22 | Computed at load time from `last_activity_date` to today |
| `stale_lead` | bool | True/False | True | Computed: days_since_activity > 14 |

**Missing values**: `deal_value` is intentionally blank for New Leads.  
**Date range**: 2024-01-01 to 2025-09-30.  
**Currency**: All USD.

## Source 2: Operations Projects (`data/ops_projects.json`)

Represents project/order records from an operations system such as Plunet.

| Field | Type | Format | Example | Notes |
|---|---|---|---|---|
| `project_id` | string | OPS-XXXX | OPS-0001 | Unique; primary key |
| `client_id` | string | Title Case | Apex Corp | Client company name; **join key to crm.company** |
| `status` | category | — | In Progress | One of: Open, In Progress, Completed, Overdue, On Hold |
| `service_type` | category | — | Translation | One of: Translation, Localization, Transcription, Interpretation, Voiceover, Subtitling, DTP |
| `created_date` | date | YYYY-MM-DD | 2024-02-10 | Project start date |
| `due_date` | date | YYYY-MM-DD | 2024-03-10 | SLA deadline |
| `completed_date` | date | YYYY-MM-DD | 2024-03-08 | Actual completion (null if not done) |
| `amount` | float | USD | 12500.00 | Project revenue |
| `assigned_team` | category | — | Team Alpha | One of: Team Alpha, Beta, Gamma, Delta |
| `sla_status` | category | — | Met | One of: Met, Breached, Pending |
| `sla_days` | int | days | 28 | Days from created_date to due_date |
| `currency` | string | — | USD | Always USD in prototype |
| `is_overdue` | bool | True/False | False | Computed: due_date < today AND status != Completed |

**Missing values**: `completed_date` is null for non-completed projects.  
**Date range**: 2024-01-01 to 2025-09-30.

## Join / Mapping Rules

| Join | Key | Type | Assumption |
|---|---|---|---|
| ops ↔ crm | `ops.client_id = crm.company` | Left outer | Company names match exactly; ~5 unmatched ops clients expected |
| crm + targets | `month + owner` | Inner | Revenue actuals (Won deals) vs. monthly targets by owner |

### Unmatched Records
- ~5 ops `client_id` values do not appear in `crm.company` — by design, to simulate real-world data gaps.
- These are shown in the Data Quality tab and the combined Sales-to-Ops chart (red bars).
- They are **not excluded** from operations metrics.

### Double-Counting Prevention
- Sales KPIs use `crm_leads.csv` only.
- Operations KPIs use `ops_projects.json` only.
- The joined table is used **only for the combined view** — never for aggregations shown on individual dashboards.
